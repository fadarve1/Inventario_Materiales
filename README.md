# Catálogo de Inventario

Catálogo web para consultar los artículos disponibles en el inventario.

## Características

- Consulta de artículos.
- Búsqueda por descripción, código o número de item.
- Filtro por categoría.
- Filtro por ubicación o embalaje.
- Visualización de cantidades.
- Visualización de precios actuales.
- Visualización de fotografías de los artículos.

## Fuente de información

La información del catálogo se mantiene en el archivo:

`INVENTARIO_FINAL.xlsx`

La versión definitiva de los datos se administra en Google Sheets.

## Imágenes

Las fotografías de los artículos se almacenan en Google Drive.

Los archivos utilizan el siguiente formato:

`img_item###.jpg`

Por ejemplo:

`img_item001.jpg`

## Tecnología

- HTML
- CSS
- JavaScript
- Google Sheets
- Google Drive

## Publicación

El catálogo está diseñado para ser publicado gratuitamente mediante GitHub Pages.
